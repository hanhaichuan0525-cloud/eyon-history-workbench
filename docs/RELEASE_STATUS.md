# 0.11.0 扩展候选 / 0.10.0 稳定状态

## 0.11.0 扩展候选

- 已完成：根扩展清单、相对仓库加载器、版本/更新钩子、能力契约、宿主 API 回退桥、文档与本地构建。
- 已通过：类型检查、726 项运行时测试、正则契约和生产构建（以本次收口结果为准）。
- 未完成：在真实 SillyTavern 扩展管理页完成 Git 安装、重载、更新、禁用、删除和断网回退验收；未创建或推送新的 GitHub tag/release。
- 发布边界：在真实酒馆验收前，0.11.0 只能视为扩展候选，不应称为稳定版。

扩展版与 JSON 版必须二选一。扩展版的自动更新由 SillyTavern 的更新器控制，不能保证每次启动都立即联网检查；扩展更新失败时不应覆盖旧版本。

## 发布范围

本版包含五栏工作台、伊雍像素伴生体、传记、宗族谱系、墟境四阶段与地点写回、墟境任务、遣返与蝴蝶效应、Canon 连续性和本地档案管理。

## 验收口径

- 自动化：`pnpm test:regex`、`pnpm typecheck`、`pnpm test`、`pnpm package:release` 必须全部通过。
- 构建：`manifest.json` 中六个入口的 SHA-256 必须与实际文件一致。
- 安全：运行时代码与发布包不得包含凭据、用户绝对路径或远程可执行代码；已知 HTML 注入点必须只消费静态模板或经过转义的数据。
- 真机：既有内测已覆盖主要生成、进入、遣返、档案和视觉流程。稳定版只做版本、文档与打包收口；发布后仍建议按 [`INSTALL.md`](INSTALL.md) 执行一次最短冒烟测试。

## 不属于 0.10.0 的承诺

- G-01B：候选不足时的专用诊断与补救交互；
- 特殊宗族双轨身份：穿越者、构装体、机器人、灵魂夺舍等“载体年龄/身份年龄”模型；
- G-07：虽然句柄迁移已实现并通过自动化，仍缺一轮专项真实酒馆复验；
- 对任意第三方角色卡扩展、未知 MVU 分支或非标准宿主的兼容保证。

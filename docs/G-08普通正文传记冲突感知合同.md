# G-08 普通正文传记连续性与冲突感知 · 实施合同与验收

> 合同状态：**FROZEN / IMPLEMENTED / AUTOMATED / DRIVER-PENDING**
> 冻结日期：2026-09-27
> 所属路线：普通聊天记忆“源 B”——已提交传记的低权连续性摘要
> 依赖能力：P4-A/A2 当前锚、P4-C 当前关系；P4-C2 的叙事原则可复用，但 G-08 不属于 P4 完成分母
> 实施版本：internal.118；已获驾驶员授权与 G-09 同批实施。未授权安装或正式发布。

## 1. 一句话目标

G-08 只解决一件事：

> 当普通角色扮演正文真正涉及已提交传记中的人物、地点、物品或事件时，让正文记得相关低权连续性；若该连续性存在尚未裁定的 P4-C 冲突，让世界中的叙述与人物以符合认知范围的方式产生疑惑，而不是静默选边或完全失忆。

G-08 不是第二套 Canon Memory。它向普通正文提供的是“同版作品曾怎样解释过历史，以及哪里仍有争议”，不是“世界已经确认发生了什么”。

## 2. 与现有源 A 的权威分离

普通正文现有源 A 是已验收的蝴蝶 `CANON_MEMORY`：它承载当前分支仍有效的改变后正史。

G-08 增加源 B：当前分支、当前 revision 中仍可消费的传记连续性摘要与 P4-C 关系。

冻结顺序：

1. 当前 Canon / `CANON_MEMORY` 始终优先；
2. 玩家本轮明确指令决定本轮叙事方向，但不能越权修改 Canon；
3. G-08 源 B 只在不与以上内容冲突时提供低权记忆与未决疑问；
4. 重复引用、剧情篇幅或模型偏好都不能提升源 B 权威；
5. 若源 A 已裁定，源 B 中不兼容视图必须退出，不得继续制造假疑云。

实现可以复用现有普通正文私密注入生命周期，但必须让源 A 与源 B 在语义和诊断上清楚分栏。不得把低权传记摘要伪装成 Canon 简报，也不得另开无界的第二套常驻记忆系统。

## 3. A0 工程门

### 3.1 输入

- 当前聊天、当前分支、当前 Canon revision；
- 当前有效 P4-A/A2 传记连续性锚；
- 当前有效 P4-C `parallelView/sourceConflict` 关系；
- 最近可见正文、玩家当前输入与当前场景可取得的人物、地点、物品和事件线索；
- 当前 Canon Memory 与 P2 状态；
- 已有资料对冲突成因的明确说明。

### 3.2 输出

- 只在相关时注入的短自然语言“传记连续性记忆”；
- 关系存在时，包含两个版本、差异位置和“当前未裁定”的关系感知摘要；
- 普通正文中的自然疑惑、证据不一致、记忆冲突、传闻分歧或其他符合场景的表现；
- 符合人物知识范围的反应；
- 工作台中可解释的入选、排除、预算与失效诊断。

### 3.3 红线

- 不把所有传记常驻注入普通正文；无关时必须为零；
- 不自动选择 P4-C 赢家，不用“最新传记”“出现次数”或“篇幅更长”决定真相；
- 不让所有人物突然知道只有系统、史官或玩家才知道的冲突；
- 不回显 `parallelView`、`sourceConflict`、anchorId、revision 等内部词；
- 不新增模型输出字段，不要求普通正文返回记忆使用回执；
- 不固定“疑惑表现类型”，不建立反应枚举、台词模板或每次必出现档案的套路；
- 不把传记里的天气、临时台词和一次性装饰全部注入；
- 不让源 B 挤掉或改写源 A Canon Memory；
- 不因记忆读取、相关性判断或注入失败而阻断普通正文；
- 不写回世界书、MVU、Canon、传记或关系记录；
- 不在本合同中实现 P4-C2、P4-D、G-09 或其他普通聊天记忆改造。

### 3.4 退出条件

1. 相关普通剧情能自然记起已经提交的传记连续性；
2. 命中冲突时，正文表现出尚未解决的世界内疑问，不静默选边；
3. 已有成因时沿用，未知成因时只提出与场景相容的疑问或暂定假说，不冒充结论；
4. 人物认知与其身份、在场、接触证据和既有经历一致；
5. 无关话题零注入，旧史不越界；
6. Canon 裁定、revision 前进、删除与回滚能确定性收缩或恢复；
7. 源 B 失败不影响源 A 和普通正文生成；
8. 注入没有变成固定悬疑模板或机械复读传记摘要。

## 4. 相关性合同

G-08 源 B 默认不是常驻记忆。只有当前输入与最近场景能够命中相关的人物、地点、物品、事件、时间或已知关系时，才允许进入候选。

相关性必须满足以下纪律：

- 复用已验证实体、P4 锚索引与当前场景信息；
- 允许宽召回，但最终只投递强相关的短摘要；
- 单纯出现“历史、以前、传说、书”等泛词不能拉入旧传记；
- 共用一个物品名称只能开启候选，不能证明当前场景正在讨论同一事件；
- P4-C 关系必须成组投递，不能只给模型一边后声称“存在冲突”；
- 任务只与某个低权事实相关但与其冲突无关时，可以投递该事实而不强迫正文讨论争议；
- 当前 Canon 已排除的锚不得因关键词命中复活。

## 5. 关系感知摘要

G-08 注入的不是普通“传记摘要拼接”，而是有权威标记的关系感知摘要。它至少需要让正文理解：

- 旧作品明确采用过哪些相关事实；
- 哪两个版本被 P4-C 判为同一事件的不同表达；
- 差异落在时间、地点、参与者、关系、所有权、物品状态或结果中的哪一面；
- 当前是相容并存还是有来源的明确冲突；
- 当前 Canon 是否已经裁定；
- 若已有冲突成因，哪些部分是明确事实，哪些仍只是解释。

这些内容由脚本整理成短自然语言，只供主模型理解。普通正文不需要也不允许输出结构化回执。

## 6. 正文如何产生疑惑

### 6.1 疑惑必须属于世界，而不是系统

正文应通过当前场景真实可用的载体感知差异，例如人物看到、听到、记起、触摸或推理到某种不一致。具体表现由模型结合文风和情境自由决定。

它可以表现为语言、动作、沉默、错误记忆、物件痕迹、制度矛盾、传闻分歧、环境异常或其他任何自然形式。这里不建立表现类型表，也不要求每次使用同一种“发现两份档案”的桥段。

### 6.2 人物认知边界

正文知道存在可供叙事使用的低权冲突，不等于所有角色拥有系统全知。

- 有资格接触史料、档案、见证者或相关物件的人，可以明确比较两个版本；
- 亲历者可以表现为记忆不适、否认、迟疑、隐瞒或确信其中一版，但其主观确信不等于 Canon；
- 普通市民可能只知道一种地方说法、模糊传闻或完全不知情；
- 没有接触渠道的人不得准确报出两个年份和全部争议细节；
- 旁白只能在当前叙事视角允许时提示异常，不能用系统上帝视角替人物完成调查。

### 6.3 已有原因与未知原因

- 若有效资料已经解释冲突来源，正文应自然承接该原因；
- 若原因未知，正文可以产生疑问、提出人物层面的猜测或留下调查方向；
- 普通聊天不得仅凭一次随口猜测彻底解决冲突；
- 模型可以让某个猜测在当前场景很有说服力，但必须保留它仍是角色判断或低权解释；
- 深入构造和游玩冲突形成因果属于 P4-C2 墟境职责，G-08 负责让普通世界记得“这里值得怀疑”。

### 6.4 不强迫所有相关场景变成调查剧

若当前主线只是经过相关地点、使用相关物品或与相关人物交谈，冲突可以只留下一个轻微但真实的叙事反应。只有玩家追问、证据进入场景或冲突直接影响行动时，才应扩大为调查、争论或剧情目标。

## 7. 不固定解释与表现类型

G-08 与 P4-C2 共享同一原则：冻结叙事责任，不冻结模型的文学实现。

合同不得要求模型从“篡改、洗脑、讹传、误记、历法、手续”等列表里选一项，也不得用关键词把世界强行分类。模型应根据：

- 当前文风与叙事视角；
- 人物身份、关系和知识渠道；
- 冲突涉及的具体对象；
- 已有证据与缺口；
- 当前场景需要的节奏和情绪；

自由决定疑惑如何浮现。验收关注的是“是否自然、是否守权威、是否可感知”，不是“是否命中某种预设写法”。

## 8. 预算与注入生命周期

- 源 A Canon Memory 永远先于源 B 分配预算；低权传记摘要不能挤掉当前正史；
- 源 B 必须有独立上限，每次只投递最相关的少量锚和最多一个完整关系簇；
- 关系簇必须包含两边，预算不足时整簇省略，不投残缺半边；
- 精确字符预算在实施前根据现有 2400 字 Canon Memory 真机余量确定，但必须保持有界并进入自动化；
- 刷新生命周期复用生成前、切聊天、删楼、回滚与手动重算等现有可靠时机；
- 当前输入与最近场景不相关时，源 B 为空；
- 切换聊天、分支或 revision 时，不复用旧源 B；
- 删除生产传记、关系成员退出或 P2 判定失效时，下一次刷新必须收缩；
- 回滚恢复父 revision 后，父版本仍有效的低权记忆可以恢复。

## 9. Canon 裁定后的行为

若世界书或正式蝴蝶 Canon 后续明确裁定其中一版：

- 不兼容视图按 P2/P4 当前性退出；
- 普通正文不再把已排除版本当作当前等可能真相；
- 旧传记原文仍可作为历史作品存在，但不进入当前源 B；
- 若当前场景本身研究“旧史为何写错”，可以把失效版本作为已知错误记录或历史遗留讨论，但必须由当前有效证据支持；
- 删除遣返楼回滚后，原双视图与疑惑资格恢复。

## 10. 失败降级

| 故障 | 正确处理 | 禁止行为 |
|---|---|---|
| 无相关传记锚 | 源 B 为空，普通正文照常 | 扫描全部旧稿猜摘要 |
| 关系只有一边可用 | 不注入冲突组；可按普通单锚处理 | 伪造另一边 |
| 相关性不确定 | 保守不投或只投单条明确事实 | 泛词触发整库 |
| 摘要组装失败 | 清空本轮源 B；源 A 与正文继续 | 中断生成或复用旧 revision 缓存 |
| 模型忽略疑云 | 正文仍有效，留下诊断供真机判断 | 自动重试普通聊天或强塞固定台词 |
| 模型擅自选赢家 | 属验收失败，修订提示边界 | 将选中结果写回 Canon |
| 角色出现全知 | 属验收失败，收紧认知边界 | 给所有人物统一记忆模板 |
| Canon 已裁定 | 过滤不兼容视图 | 为了戏剧性继续制造未决冲突 |

## 11. 实施边界

未来得到明确授权后，第一版只允许：

- 从当前 BiographyRecord/P4 视图构建有界源 B 摘要；
- 复用普通正文现有私密注入生命周期；
- 保持源 A/源 B 权威分栏与诊断；
- 增加相关性、预算、生命周期和正文行为测试；
- 更新工作台只读诊断、文档、NEXT、构建和组件包。

第一版不做：

- 让普通聊天生产新的 P4 锚或关系；
- 从普通正文反向抽取事实；
- 自动把角色猜测写回传记、世界书或 Canon；
- 长期跨聊天“世界总史”；
- 向量数据库、embedding 或外部语义服务；
- 人工“设为真相”按钮；
- P4-D 缓存或 G-09 档案删除语义。

## 13. 最短真机验收

1. 保留两篇时间冲突的《暮潮手札》传记；
2. 在普通聊天中让角色接触手札、洛安、弥拉或第七泊位相关证据；
3. 确认正文自然察觉 484/485 的不一致，但没有宣布哪一版是正史；
4. 换成无权接触档案的普通人物，确认其认知受到限制；
5. 转入完全无关话题，确认源 B 不再出现；
6. 通过正式 Canon 流程裁定一个年份，确认疑问收缩；删除遣返楼后确认恢复；
7. 导出源 A/源 B 诊断，核对 Canon 简报未被传记低权内容覆盖。

> 驱动：驾驶员要求「任何模块不得因时空错位报错截断；AI 必须知道矛盾，并把矛盾转化为可行方针」

## 1. 目标（最低要求，写死）

1. **任何模块不得因时空错位而报错截断**（人物缺席 / 种族灭绝 / 科技未出 / 疆土未属 / 制度未建，包罗万象）。
2. AI 必须知道矛盾（不无声当作原生事物），并把矛盾转化为可行方针：
   - **缺席叙事**：描写该元素缺席时世界的状态、到来前的空白、遗产在当下的痕迹；
   - **异界来源**：位面交汇残留 / 异界造物 / 古神遗物 / 时间异常，并明示来源。
3. **谱系例外**：人物生卒年严格判定（血缘是关系数据，错位 = 逻辑错误；且谱系结果作为事实源进入下游）。
   - 例外是**共通机制的一个策略档位**（`strict`），不是共通机制之上的覆盖补丁。

## 2. 架构决策：错位处理是共通机制，模块声明策略

```
统一时间资格管线（共通）
  ├─ 输出：错位判定（四态画像 + 人物时间锚）+ 处理策略档位
  ├─ 策略档位：
  │    accommodate（容纳）—— 叙事模块：墟境 / 传记 / 蝴蝶
  │    strict（严格）     —— 结构模块：谱系
  └─ 模块通过任务画像声明自己的策略，同一管线、零覆盖、零补丁
```

- 共通管线产出：`AnachronismAssessment { state: exists|notYet|extinct|unresolved, strategy, narrative: string }`；
- 叙事模块：把 `narrative` 方针写入 prompt（缺席叙事/异界来源），validator 不因错位拒绝；
- 谱系：`strict` 档——人物出生年/在世区间与目标纪元严格相容，失败走既有 repair（带指引），不搞缺席叙事。

## 3. 四态画像（ERA_PROFILE 扩展）

| 状态 | 判定 | 来源 |
|---|---|---|
| `exists` 已存在 | availableFromEra ≤ 目标纪元 且未灭绝 | 权威年表 created/formed 规则 |
| `notYet` 尚未出现 | availableFromEra > 目标纪元 | 权威年表 created/formed 规则 |
| `extinct` 已灭绝 | destroyed/dissolved 事件发生在目标纪元之前 | 权威年表生命周期规则（Temporal v2 已解析 eventType） |
| `eraFeatures` 时代特征白描 | 年表 + 世界主设定生成的该纪元底色 | "神明纪元：无国家制度、无宗教体系、无工业技术" |

- `extinct` 与 `eraFeatures` 是新增；`exists/notYet` 已上线（internal.51）；
- `eraFeatures` 承担"世界书没明文的概念"（如蒸汽机）：模型看时代底色 + 常识归类 → 冲突 → 按错位契约处理。

## 4. 人物时间锚（年龄换算，基准 = 开局锁定）

- **基准锁定（驾驶员拍板）**：新增 `settings.baselineWorldTime`（脚本变量持久化，仿 storyClock）。**首次任务（任一模块 assemble）时把当时的 `currentWorld.time` 锁定为基准**，此后所有年龄换算都以它为基准，不随每楼剧情时间漂移；换新聊天/角色卡（脚本变量重置）时重新锁定；玩家自定义开局时间天然成为基准。
- 时间语义区分：`baselineWorldTime` = 年龄/角色数据的基准（开局锁定，恒定）；`currentWorld.time` = 剧情当前时间（每楼动态，用于时代画像与目标纪元判定）。
- 输入：catalog 实体（含 `年龄: N岁` → `lifespan.ageAtRecord`，或显式生卒年）；
- 换算：`出生年 = 基准年 − 年龄`；跨纪元用 `ERA_SEQUENCE`；`年龄 > 基准年` 或解析失败 → 不生成事实（不误伤）；"界外来客/来自异界/穿越" → 标 `arrivalBased`；
- 输出：引擎计算 `personTimeline` 写入 EvidenceBundle，prompt 渲染 `<PERSON_TIMELINE>`——"梅薇娜·王尔德：当前（复兴纪元X年）88岁 → 出生/抵达约 Y 年（由基准时间推算）；目标纪元 Z 年 → 结论（在场 / 未出生 / 已故 / 未知）+ 对应叙事方针"。
- **脚本算好给模型，不让模型心算**；换算结果带基准标注（`basedOnEra/Year`、`ageBased`），谱系硬门只用显式生卒，`ageBased` 不参与硬门。

## 5. 统一错位契约（覆盖所有类别）

```
<时空错位处理契约>
当设定/输入要求出现与本纪元冲突的元素（人物缺席/种族灭绝/科技未出/疆土未属/制度未建）：
1. 承认冲突是历史事实（不得无声当作原生事物）；
2. 二选一：
   A. 缺席叙事：描写该元素缺席时世界的状态、其到来前的空白、其遗产在当下的痕迹
      （例：「梅薇娜尚未穿越至阿斯塔利亚时，晨曙书局……」；「该种族灭绝百年后，其城市成为废墟」）；
   B. 异界来源：位面交汇残留/异界造物/古神遗物/时间异常，并明示来源；
3. 无法自洽时降级为同功能的本纪元对应物（蒸汽机 → 魔导蒸汽机关）。
</时空错位处理契约>
```

- 契约文案由 internal.51 版本扩展（现只覆盖实体/制度 → 覆盖全部类别 + 人物缺席句式）。

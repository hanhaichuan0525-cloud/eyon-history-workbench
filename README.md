# Eyon History Workbench

伊雍历史工作台是为《命定之诗》角色卡设计的历史探索系统。

当前计划包含：

- 墟境时空与状态查看
- MVU 人物查看与本地自定义分组
- 宗族谱系生成
- 墟境历史与因果节点生成
- 寻根溯源与传记书库
- 独立蝴蝶效应结算
- 按角色卡与聊天隔离的本地资料库
- 远程版本检测、缓存与回退

## 当前阶段

仓库已经进入契约层实现阶段：

- `rules/` 保存已经确认的脚本嵌入契约。
- `worldbook/` 保存与脚本配套的伊雍核心世界书副本。
- `src/core/` 负责严格命令识别、请求占位槽和聊天命名空间。
- `src/renderers/` 负责输出能被现有酒馆美化正则识别的固定原文。
- `src/adapters/` 定义酒馆、生成接口和世界书归档边界。
- `prototype/` 继续作为交互与视觉规格，不直接充当正式运行代码。

稳定的墟境时间控制模块不在本仓库中重写；历史工作台只通过受限适配层读取其状态。

## 设计边界

- 世界书继续负责伊雍人设、正文格式和角色卡核心。
- 现有时间模块继续负责墟境状态、时间与地点。
- 独立 API 负责宗族谱系、墟境历史、寻根溯源和蝴蝶效应内容生成。
- 工作台负责检索、调度、校验、存储、渲染和受控注入。
- 不读取或修改记忆插件的私有数据。
- 不把 API 密钥、聊天全文或完整 MVU 对象提交到仓库。

## 本地验证

```bash
npm test
```

第一阶段测试只覆盖纯契约层，不连接酒馆、不修改 MVU，也不调用远程 API。

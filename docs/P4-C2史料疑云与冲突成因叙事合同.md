## 1. 一句话目标

P4-C2 只解决一件事：

> 当相关墟境命中尚未裁定的 `parallelView` 或 `sourceConflict` 时，不把数据库差异原样丢给玩家，而是把“为什么后世会留下两种说法”编织成世界内部可观察、可追查、可干涉的历史疑云。

P4-C 负责发现和保存差异；P4-C2 负责让差异在墟境中成为叙事。P4-C2 不判断哪一版是真相，也不把一个写得漂亮的解释自动升级为 Canon。

## 2. A0 工程门

### 2.1 输入

- 当前聊天、当前分支、当前 Canon revision 中仍可消费的 P4-C 关系；
- 每个关系最多两个当前视图、差异维度及其低权自然语言锚；
- 当前 P1—P3 Canon 视图，只用于排除已经失效的版本和约束不可改事实；
- 本轮墟境的时间范围、地点、人物、对象、玩家补充方向和既有 Active Evidence；
- 已有正文或来源中对冲突成因的明确说明；
- 既有墟境候选、`canonInterpretation`、节点与史稿正文合同。

### 2.2 输出

- 与本轮墟境相关时，融入既有候选与史稿的“冲突形成因果”；
- 与玩家所选时间窗相适配的前置引子、后置残迹或完整分裂过程；
- 至少一种能在世界内部被人物感知或调查的痕迹；
- 对未裁定部分保持诚实的局部历史假说；
- 无关时零注入、零强行疑云。

### 2.3 红线

- 不新增 `causeType`、`mysteryType`、固定解释枚举或模型必填结构字段；
- 不把“篡改、洗脑、讹传、历法差异、登记延迟”等示例写成穷举菜单或轮流套用的模板；
- 不要求每个冲突都变成阴谋、侦探案、档案室或神秘人作祟；
- 不把两个互斥版本写成两次都已确定发生，除非当前证据明确支持归还、重演、伪造物或第二次交接等独立事件；
- 不让模型选择全局赢家，不写回 Canon，不创建蝴蝶 delta；
- 不覆盖玩家任务主轴，不把一个次要史料差异抢成所有墟境的唯一主题；
- 不恢复全文拆句事实库、语义编译器或无限上下文；
- 不因关系缺失、解释困难或模型发挥不足而阻断墟境生成；
- 不进入普通聊天注入；普通正文由独立的 G-08 合同负责；
- `runtimePersistentBlueprintBudget = 0`，本阶段不得再派生新的持久子蓝图。

### 2.4 退出条件

只有同时满足以下条件，P4-C2 才能交给驾驶员验收：

1. 相关墟境能意识到 P4-C 已记录的差异；
2. 已有明确成因时忠实沿用，不另造竞争解释；
3. 没有明确成因时，模型能结合当前世界自由编织局部因果，而不是套固定模板；
4. 只覆盖较早年份、只覆盖较晚年份、同时覆盖两端年份时，叙事责任不同且正确；
5. 冲突通过世界内证据、行动、记忆、制度或物质痕迹呈现，不回显内部术语；
6. 未裁定解释仍保持低权，不因进入墟境自动成为 Canon；
7. 无关任务、已被 Canon 裁定的旧关系和坏关系不污染墟境；
8. 失败时回退为普通墟境，不新增 repair 循环。

## 3. 叙事智能原则：冻结责任，不冻结解释类型

### 3.1 禁止解释类型表驱动正文

合同只规定“必须解释什么”和“不能越过什么”，不规定“必须用哪一种解释”。模型应从本轮已有材料中综合判断：

- 哪些人真正有机会接触相关事件；
- 哪种制度、媒介、物件、记忆、魔法、社会习惯或自然过程可能留下两种记录；
- 冲突发生在事件、记录、传播、保存、解释还是后世命名的哪一环；
- 玩家能在当前时间与地点感知到什么，而不是系统内部知道什么。

史官篡改、群体记忆改变、民间故事讹传、历法换算、私人交付与正式登记不同步、物品被退回或重新确认，都只能作为帮助理解的非穷举例子。实现不得把这些词做成固定分类器、随机表或必选清单。

### 3.2 冲突必须融进已有叙事

模型不必另开“史料疑云说明”章节，也不必让人物停下来讲解设定。冲突可以自然存在于：

- 一个动作没有完成的后果；
- 某件物品不合时宜的磨损、封签或所有权痕迹；
- 人物记忆与眼前证据之间的不适；
- 两个机构对同一行为采用不同生效标准；
- 一段传播过程中发生的省略、误认、隐瞒或再解释；
- 环境、仪式、技术或超自然机制留下的可验证异常；
- 玩家本轮行动能够碰触的任何其他叙事载体。

上述仍是表现方向，不是格式。合格标准是玩家能在故事中感到“这两种历史为何会同时存在”，而不是能从正文里勾选某个预制原因。

### 3.3 解释应有边界和代价

自由发挥不等于无限扩张。模型编织的局部因果应当：

- 足以解释当前这组差异，不顺手重写整个国家、文明或全部人物记忆；
- 优先使用已有角色、制度、物件和机制；需要新增局部人物或细节时保持最小影响半径；
- 留下至少一种与本轮场景相容的可感知痕迹；
- 不制造比原冲突更大的无依据高权事实；
- 保留其他解释仍可能成立的空间，除非当前 Canon 已经裁定。

## 4. 既有成因优先

在自由编织前，模型必须先检查当前投递材料是否已经说明冲突为何产生。

“已有说明”可以来自：

- 当前有效世界书、MVU 或 Canon；
- 两篇关系成员传记的明确正文；
- 当前有效的另一篇连续性锚；
- 与本轮相关且有资格使用的墟境、蝴蝶或人物资料；
- 玩家本轮明确给出的解释。

若已有说明：

- 沿用其核心因果，不换成更戏剧化但冲突的新故事；
- 可以补充现场细节、人物反应和可感知证据；
- 不得把“据说、怀疑、官方声称”升级为客观事实；
- 多个已有解释仍互斥时，继续作为多个可能性呈现，不擅自合并。

## 5. 没有既有成因时的自由编织

如果当前资料只表明“同一事件存在差异”，却没有说明差异如何形成，模型必须为本轮墟境构造一条自洽的局部成因假说。

这条假说不需要遵循固定槽位，但正文整体应让读者能够回答三个自然问题：

1. 两种说法从哪里开始分岔；
2. 哪些行为、媒介或环境让分岔得以保存或传播；
3. 玩家在当前场景为什么有机会察觉它。

模型可以让原因在人物选择、制度流程、物品流转、语言误解、超自然效应或其他符合世界观的过程中自然生长。禁止为了“完成疑云任务”硬塞一个与人物和时代毫无关系的万能阴谋。

自由生成的成因属于**本候选采用的低权解释**：

- 可以在该候选史稿中完整成立；
- 可以成为玩家进入后调查和干涉的对象；
- 不反向证明两篇传记中的任一篇是真正正史；
- 不进入 P1—P3，除非玩家行动经过遣返与蝴蝶效应正式归档。

## 6. 时间窗决定叙事责任

以下是覆盖原则，不是固定文案模板。

### 6.1 只覆盖较早版本的时间

墟境不能提前把较晚版本写成已经发生，但应在当前故事中留下足以通向后续差异的因果种子。

种子必须是本轮可体验的未完成状态、选择、痕迹或条件，而不是旁白预告“明年史书会写错”。它可以在未来发展成另一种记载，也可以因玩家干涉而改变方向。

以“暮潮移交”为例，若只探索 484 年，正文可以让交付尚未获得承认、物品暂时停留在过渡持有人手中，或让某个以后会影响记录的条件在此形成；但不得直接宣布 485 年版本已经成为事实。

### 6.2 只覆盖较晚版本的时间

墟境应让较早说法以残留证据、人物记忆、旧手续、物品痕迹或其他世界内方式留下影响。较晚现场可以否认、质疑或重新解释它，但不能让较早版本无声消失。

以“暮潮移交”为例，若只探索 485 年，玩家应有机会接触为什么有人坚持 484 年已经完成移交的痕迹，而不是只看到一个毫无疑问的 485 年首次交付。

### 6.3 时间窗覆盖两个版本

墟境应展示冲突如何形成、分流并留下两套可持续记录。它不必写成说明书式时间线，但玩家应在行动和后果中经历这条分裂过程。

模型可以将同一事件的开始、生效、公开、登记、记忆或后世命名拆成自然的叙事过程；也可以提出完全不同但与证据相容的形成机制。不得仅把两个版本分别抄一遍而不解释它们为何会并存。

### 6.4 时间窗不覆盖任一版本

只有当该冲突构成本轮事件的必要前史、后果或调查对象时才投递。否则零注入，不为了展示 P4-C2 而强行制造历史谜题。

## 7. 不只适用于时间冲突

P4-C2 必须能够消费 P4-C 已允许的其他差异维度：地点、参与者、关系、所有权、物品状态和结果。

合同不为每个维度写死一套原因表。统一要求是：

- 找出两个视图不能同时按字面成立的落点；
- 让差异在本轮世界中有形成过程和可感知痕迹；
- 避免把相邻但不同的事件误写成同一事件；
- 不因解释冲突而修改高权身份、亲缘、生卒或 Canon 状态。

## 8. 候选与史稿行为

### 8.1 候选阶段

- 若关系与本轮强相关，至少一个可进入候选必须真正承载史料疑云，而不是只在隐藏推理中提到；
- 多个候选可以采用不同但证据相容的解释方向，前提是它们的行动、机制和后果确实不同；
- 不要求所有候选都围绕同一冲突展开；玩家原始任务仍是主轴；
- 复用既有 `alternative-interpretation` 与 assumptions/alternatives 能力，不增加新的模型结构字段；
- 候选不得以“换一个年份”冒充不同剧情。

### 8.2 史稿扩写

- 选中候选后，史稿必须把成因落实到场景、行动和结果中；
- 不回显 `parallelView`、`sourceConflict`、句柄、revision、低权锚等内部术语；
- 不以百科说明代替人物行动；
- 不在结尾替 Canon 宣判唯一真相；
- 若史稿只能提出部分解释，应把未解部分留成世界内悬念，而不是假装已经闭合。

### 8.3 进入与遣返

- 进入某个候选表示本次游玩采用该局部历史假说，不等于全局正史已经选定；
- 仅观察、调查或经历疑云不会自动修改 Canon；
- 玩家在墟境中的实际干涉及遣返后的蝴蝶效应，仍是正式改变 Canon 的唯一叙事入口；
- 蝴蝶结算只记录玩家真实行动与经验证后果，不得把整套候选假说自动打包成既成正史。

## 9. 相关性、预算与失败降级

- 继续使用 P4-A/P4-C 既有相关性筛选、每簇最多两个视图及 6 锚/1600 字总预算；
- 不新增第二份无限冲突上下文，不回扫全部传记；
- 没有相关关系时，墟境提示词与现有行为一致；
- 关系存在但当前预算不足时，优先保留与玩家任务直接相交的一个完整关系簇，不投递残缺半边；
- 当前 Canon 已裁定时，只投递仍相容的事实，不继续制造已经失效的疑云；
- 关系读取、组装或叙事指令失败时，回退为普通墟境；正文仍可生成；
- 不因为模型没有完美解释疑云而 repair 整份史稿；只有既有硬事实合同被破坏时才走原有 repair。

## 12. 最短真机验收

使用当前已验收的两篇《暮潮手札》传记：

1. 生成仅覆盖 484 年的相关墟境，确认正文留下可能导致 485 年记载的引子；
2. 生成仅覆盖 485 年的相关墟境，确认正文能看到 484 年说法留下的痕迹；
3. 生成覆盖 484—485 年的相关墟境，确认至少一份候选把冲突形成过程写入剧情；
4. 改用无关人物和地点生成墟境，确认暮潮疑云不出现；
5. 检查候选与史稿不得出现内部术语，不得宣布任一版本为 Canon；
6. 若后续通过正式 Canon 流程裁定年份，再重生成并确认旧疑云退出；删除遣返楼后确认恢复。

自动化、typecheck、构建、组件包、真实酒馆和驾驶员接受仍是独立证据门。internal.116 已完成前四项并获得多轮真实酒馆观察；驾驶员最终选择“保持当前实现、停止继续围绕该样本修补”。因此本阶段以 `DRIVER CLOSED WITH KNOWN LIMITATION` 收口，不能被后续文档改写成 HM 全表严格 PASS。

## 13. internal.113 实施回执

### 13.1 实际改动

- 墟境提示词新增 `<HISTORICAL_AMBIGUITY_NARRATIVE_READ_ONLY>` 只读区块，只在当前连续性视图含有效关系簇时出现；没有关系时返回空，不制造额外上下文。
- 时间差异由脚本只计算“本候选需要承担什么叙事责任”：较早端留下可生长的因果种子，较晚端保留早期说法的可查痕迹，跨越两端时呈现分歧形成、传播或保存的过程；自动时间范围按候选实际 span 判断。
- 地点、参与者、关系、所有权、物品状态和结果等非时间差异共用通用叙事责任，不套时间模板。

## 16. internal.116 独立语义裁决门

### 16.1 真机证据与根因

internal.115 的第三次 484 年单窗结果依然 3/3 越界：候选分别写出“悬置整整一年”“直至一年后解封”“留待次年完工/485 年合订”。这些句子没有直接抄录较晚传记，却仍以全知回顾确认了截止点后的完成方式。根因是整段复核只要求模型返回一份结构合法的修订稿；模型原义照返时，既有解析器只能证明 JSON 与候选结构正确，不能证明叙事真的遵守了时间认知边界。

### 16.2 最小实现

- 较早时间窗的任务投影不再暴露较晚低权锚的具体年份，只保留“本轮时间窗之后存在一份年份不同的记录”；共同人物、地点、物品和关系仍可用于组织当期疑云；
- 较早端叙事必须停在窗口内的未完成现场，不得解释、命名或总结后世为什么形成两种说法；
- 原有整段语义复核继续负责改写，但其结构合法不再等于通过；
- 改写稿随后进入一次独立语义裁决。裁判只读取候选截止时间与候选全文，不读取世界书、传记正文、较晚锚或关系答案；
- 裁判只返回 `PASS` 或 `BLOCK` 控制回执。它不是历史事实字段，不写入候选、关系、存储或 Canon；
- 完成于截止点之后的手续/交付、精确未来日期、跨越截止点的持续时长、后来的正式归档/承认，以及“本场景后来成为史料分歧成因”的后见总结，全部判为 `BLOCK`；不确定时也 `BLOCK`；
- `BLOCK` 或畸形裁决沿用既有候选失败态与手动重试，不回退泄露未来的草稿，不追加循环 repair。

### 16.3 边界

- 仅明确且完整落于 `time` 冲突较早端的候选触发“复核 + 裁决”；
- 普通、较晚、跨越两端、自动范围及非时间冲突路径保持零投影、零复核、零裁决；

# β1.8 发布说明

发布日期：2026-10-02。对外版本β1.8，数字更新协议0.14.14。
比较基准：公开β1.7 / 0.14.9。整合本地0.14.10—0.14.13修复，本轮仅统一版本、验证和发布。

## 相比β1.7

1. 人物检索：自然称号、旧称、事件名与散文中的明确关联可跟读人物；标题作者、字段、数字与模板代码不冒充人名。明确亲属方向可作为主体，不转借资料主人的年龄或其他亲属经历。启用来源和相关性边界保持。
2. 身份与年代：中文/数字年龄和明确纪元更易识别；MVU背景事件纪元不再另造人物身份。阶段称呼可在唯一身份且生卒无冲突时关联本人，保留同名歧义、明确出生冲突与模糊年代，不强行造年份。
3. 遣返与蝴蝶：回滚、删楼、停止和换聊天隔离旧准备事务、晚到结果和提交锁。同楼未改动重roll仍复用冻结结果，行动改变则重取。收集失败结束忙碌计时并显示可重试错误；成功契约加明确同行决定才承接赎出现世，不能从意向或失败虚构带回。
4. 完整资料与长轮次：已选世界书、MVU、聊天和跨模块史料不再按字符硬截正文；当前墟境不再只取最近24/36楼，早期契约、行动和入场可保留。途中换脚本且入口信息缺失时，可按当前回复槽位的MVU轮次证据恢复；无法辨认边界则提示，不借上一轮凑资料。仍选择相关来源，不等于无限上下文。
5. 传记防污染：首次检索和具名补查共用用途边界，伊雍运行核心不因共享地点或初稿自造名称物化成古代金属球/圣物。明确研究伊雍、核心、契约仍可读取完整设定；不一刀切排除普通器物或EJS人设，不执行EJS。
6. 跨存档隔离：延迟时地回放绑定角色卡、聊天与切换批次，核对当前正文/角色/回复槽位；切换时取消旧回放。历史记忆异步刷新只接受当前上下文最新读取，切换立即清旧提示，退役后的晚结果失效。

不新增模型必填字段、运行时依赖或模型调用，不改变已磨合的年龄、冻结大纲、Canon及身份规则，不修改玩家世界书或自动重写旧史稿。

## 更新方法及边界

- 已导入固定β1自动加载器：电脑/手机均无需重新导入。停用其他旧工作台脚本/扩展，完整刷新酒馆，核对界面β1.8。固定文件名、ID和loader 0.3.1代码保持不变；仅更新版本说明与远端清单/bundle。
- 离线包：导入本目录的`酒馆助手脚本-伊雍历史工作台-v0.14.14.json`，只启用这一套。离线包与已导入正文正则不自动更新。
- 网络/CDN旧缓存或校验失败仍可能回退已验证旧缓存；已打开页面不热替换运行时。
- 不自动恢复已经污染的MVU、聊天或外部插件记忆；需备份后从正常楼层/备份另行恢复。
- 导入本包不保证清扫所有旧iframe实例或遗留注入。必须停用旧工作台并完整刷新，不能并开多份脚本。
- 完整原文会增大请求体，模型上下文/输出容量仍有限。未知作者格式、同名卡且聊天标识完全相同等边界不作无条件保证。
- 自动测试与远端字节核对不等于真实酒馆/手机/模型叙事验收；不自动标记driver-accepted。

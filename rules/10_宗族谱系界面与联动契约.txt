# 一、界面定位

族谱是只读人物关系视图，也是墟境与传记的辅助资料选择器。

族谱不承担:

- 谱系中心的树内切换。
- 家族冲突分析。
- 继承合法性判断。
- 隐藏亲属推理。
- 任务或剧情生成。
- MVU变量修改。

# 二、入口

1. 人物查看器只列出MVU角色列表中的人物。
2. 玩家在人物查看器选中一个人物。
3. 玩家点击“宗族谱系”。
4. 该人物成为本次族谱固定中心。
5. 玩家可以调整向上代数和向下代数。
6. 重新生成只刷新当前中心人物的族谱，不自动改选其他中心。

# 三、节点显示

每个节点卡片常驻显示:

- 人物姓名。
- 与中心人物的关系。
- 生卒年份。

推荐日期显示:

- 同纪元已知生卒: `复兴纪元430—482年`
- 跨纪元已知生卒: `英雄纪元末年—复兴纪元82年`
- 在世: `复兴纪元464年—在世`
- 约数: `约复兴纪元430年—约复兴纪元482年`
- 生年未知: `生年不详—复兴纪元482年`
- 卒年未知: `复兴纪元430年—卒年不详`
- 全部未知: `生卒年不详`

已知年份不得省略纪元名。纪元只允许“创世纪元、神明纪元、混乱纪元、英雄纪元、复兴纪元”。

中心人物使用强调边框，但不改变卡片尺寸。
明确资料、合理推断与自动补全人物使用同一套节点样式，不因来源制造视觉等级差。MVU人物只通过轻量标识说明可进行墟境注入。

# 四、左键行为

## 4.1 所有族谱人物

左键点击人物节点，在固定信息框显示:

- 姓名。
- 别名与称号。
- 种族。
- 身份。
- 职业。
- 生命层级。
- 生卒年份。
- 与当前谱系中心的关系。
- 基础摘要。

信息框只显示族谱输出中的基础字段，不展开技能、装备、属性、背包或状态效果。非MVU人物同样显示API整理或补全的基础信息，但不打开MVU人物查看器。

左键不会:

- 切换谱系中心。
- 重新生成族谱。
- 修改墟境参与人物。
- 向正文发送任何文本。

# 五、右键菜单

只有 `canInjectToRuin: true` 的MVU人物节点响应右键。其他人物可以查看基础资料，但不能加入墟境参与人物。

右键菜单只保留与当前工程有关的命令:

- `加入墟境参与人物`
- 已加入时显示 `从墟境参与人物移除`

不提供:

- 设为谱系中心。
- 编辑关系。
- 添加虚构亲属。
- 生成家族冲突。
- 直接开始寻根溯源。
- 直接进入墟境。

# 六、加入墟境参与人物

玩家选择“加入墟境参与人物”后，脚本把该人物加入墟境生成表单的 `selectedCharacters`。

写入结构:

{
  "mvuId": "MVU稳定标识",
  "name": "人物名称",
  "source": "mvu",
  "race": "种族",
  "identities": ["身份"],
  "professions": ["职业"],
  "lifeLevel": "生命层级",
  "relations": ["与当前族谱中心或其他已选人物的关系摘要"],
  "lifespan": "含固定纪元的生卒信息；未知部分保持未知",
  "contextSummary": "与当前正文、地点或玩家补充方向有关的短摘要",
  "genealogyRequestId": "本次族谱请求ID",
  "genealogyNodeId": "族谱节点ID"
}

限制:

- 只保存墟境创作所需摘要，不复制完整MVU人物对象。
- 不把技能、装备、背包和数值属性发给墟境API。
- 同一 `mvuId` 不得重复加入。
- 加入人物不代表该人物已经在正文中出场。
- 加入人物不修改其MVU `在场` 状态。
- 加入人物不自动触发墟境生成。
- 玩家仍需在墟境生成界面确认并点击生成。

# 七、墟境API联动

墟境请求中的:

- `selectedCharacters`: 当前表单已选择的参与人物摘要。
- `genealogyRefs`: 只包含这些人物之间与本次候选有关的明确亲属关系。

不得把整棵族谱发送给墟境API。

族谱关系只能用于:

- 解释人物为何共同出现。
- 提供婚姻、血缘、收养、监护或继承背景。
- 连接地点、组织和历史阶段。
- 帮助三骰素材建立可信人物桥梁。

族谱关系不能用于:

- 强制生成家族冲突。
- 推定隐藏亲属。
- 判断合法继承人。
- 覆盖玩家补充方向。
- 让所有候选都围绕同一家庭展开。

# 八、寻根溯源联动

当玩家对某个MVU人物发起寻根溯源时:

- 可以把该人物当前族谱的直接亲属摘要放入 `genealogyContext`。
- 只传递与玩家方向和时间范围相关的关系。
- 族谱为空时不影响传记生成。
- 传记API可以引用明确关系，但不得扩写新的族谱成员。
- 传记API可以使用族谱中已补全的人物，但必须保留其纪元、职业、关系和基础身份，不能把补全人物伪装成世界书原文。

# 九、状态与缓存

- 族谱缓存键: `chatId + focusMvuId + depth + sourceHash`。
- 正文、世界书或MVU人物资料变化后，对应 `sourceHash` 失效。
- 切换聊天时不跨聊天复用族谱。
- 墟境参与人物列表属于当前墟境生成草稿，不属于族谱永久数据。
- 清空墟境生成草稿时，移除已注入人物，但不删除族谱缓存。
- 删除族谱缓存不影响传记书库、MVU或墟境状态。

# 十、可访问性与交互安全

- 右键菜单必须阻止浏览器默认菜单。
- 点击菜单外、按Escape或切换标签页时关闭菜单。
- 菜单位置必须限制在可视区域内。
- 左键信息框和右键菜单不能同时覆盖关键节点。
- 移动端没有稳定右键时，节点提供等价的长按菜单。
- 长按只打开菜单，不触发左键信息框。

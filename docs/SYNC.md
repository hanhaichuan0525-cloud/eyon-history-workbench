# 规则与核心同步

仓库内的规则和世界书核心来自同一工作区中的伊雍系统目录：

- `rules/00–15`: `我的核心及美化项目/命定系统/伊雍系统/新-脚本嵌入文档/`
- `worldbook/命定系统-伊雍(新).txt`: `我的核心及美化项目/命定系统/伊雍系统/命定系统-伊雍(新).txt`

仓库副本用于版本管理、脚本构建和发布。角色卡实际使用的世界书文件仍由原目录维护，不由运行时脚本远程覆盖。

同步规则：

1. 先修改并验证角色卡工作区中的原文件。
2. 再把同名文件同步到本仓库。
3. 同步后运行 `npm test`。
4. 提交时同时更新 `manifest.json` 的版本说明。

禁止只修改仓库副本却不回写角色卡工作区，否则本地测试与发布版本会产生隐蔽分叉。

## 六项行为合同

1. 局部视图：逐 node/edge 复用 P2 判断，保留原始单位和原因；明确失效排除自动复用，不确定保留只读诊断/保守引用，不作为已确定亲缘。可用关系必须有可用端点。稳定身份由脚本记录，禁止模型创造 entityId；无唯一身份不跨谱系归并。
2. 全部出口：统一来源提供器输出当前局部摘要；不输出过时全文、总摘要或关系短传。墟境显式选择在读取/生成时按当前视图重建，不物理删除选择，回滚可恢复。界面显示当前单位状态；诊断可导出。
3. 时间：使用已冻结当前 Canon 的人物 lifespan/时间原点纠正结构化生卒日期；中心人物依世界书明确生年→世界书字段年龄→MVU明确生年→MVU字段年龄→模型谱系约年的次序补齐出生时间，不用外貌/心理/抵达年龄。先纠正再检查代际；不以模糊文本推导死亡后无子女。
4. 引用：未知句柄逐项丢弃；只有在名册精确确定该人物/关系时可恢复其真实来源。名册外人物/关系作为 generated 低权补全保留，但其引用强制清空；与事实锁冲突、断连或结构无效的单个单位局部剔除。身份/格式错误最多一次既有 repair，不无限重试。
5. 非 MVU：已验证节点均可选择作为墟境参考；可复用性由当前局部视图决定，非 MVU 不写入 MVU。旧 onlyMvuNodesCanInjectToRuin 字段兼容接收但不再作权限闸门。
6. historyRefs：保持旧存档可读；模型不再负责内部 biographyId/stageId。新记录的链接由脚本从已提交同版传记锚、人物身份和有效生产单位建立；消费者每次按当前锚验证，仅作低权参考，删除/变版后停止输出。清理旧未调用的二次选源函数。

谱系消费 P4-A2 连续性短句，但不把自然语言锚编译为血缘、死亡等 Canon 事实；只有已有结构化强证据能决定硬关系。generated 亲缘只属于当前谱系的低权补全，不是 Canon 强关系。谱系本轮仍不新增独立 P4 生成锚生产格式。

## 验收用例

- GB-01：变更一条关系，只该边失效；未变人物与其他关系保留。
- GB-02：时间未知只给不确定提示；不编造死亡后代或替代父母。
- GB-03：出生/关系时间明确晚于相关死亡时，仅对应关系退出；跨纪元不猜。
- GB-04：回滚恢复原节点、边、显式墟境选择；不改原记录。
- GB-05：较新失效记录不盖掉旧有效单位；只按唯一稳定身份消重。
- GB-06：跨聊天/分支不读取；旧无绑定记录仍可看且不充当确定关系来源。
- GB-07：坏 S 句柄及一个无依据人物不令其余合法谱系报废。
- GB-08：当前出生/死亡原点覆盖错误结构日期；世界书整条目的实际年龄优先反推谱系约年，无匹配条目时保留模型给出的合年代约年。
- GB-09：非 MVU 合法人物可选择；过时节点不能偷渡给墟境。
- GB-10：同版传记事实锚进入谱系；historyRefs 删除/变版失效，伪造 ID 被忽略。
- GB-11：上下文/短引用/界面诊断不泄露内部 ID 到模型输出要求；无新模型调用。
- GB-12：全量自动化及构建；真实酒馆由驾驶员独立验收。

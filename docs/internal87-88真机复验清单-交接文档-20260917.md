## 范围二 · internal.88（§6 步 B 镜像退役）

### 5. 清理存量镜像

- [ ] 「数据管理 → 世界书注入镜像」→ 点「**清理镜像**」→ 确认弹窗（明示不删世界书文件）。
- [ ] **必过项**（不依赖宿主删除能力）：
  - 控制台出现 `butterfly mirror retired: worldbooks=N removedEntries=M globalsLeft=K`；
  - ST 世界书面板里 `伊雍-蝴蝶效应锚定-<聊天id>` **不再出现在全局世界书勾选列表**（`globalsLeft=K` 应等于"除锚定书外的原全局书数"）。
- [ ] **尽力而为项**（取决于宿主是否提供条目删除接口）：打开那本书，条目应已清空。
  - 若日志里 `removedEntries=0` 且条目仍在：**不算 FAIL**，如实记录即可——这些条目已从检索语料排除（`routed-generated`）、且没有任何代码再读它们，属"死重量"；书文件与条目后续可手动清理。
- [ ] 反例判据（真 FAIL）：锚定书**仍被勾选**、或 `worldbooks=0` 而该锚定书明明存在、或日志出现 `mirror cleanup failed` 却连绑定都没摘掉。

### 6. 检索与正文可见性无回归（最关键）

- [ ] 再走一轮蝴蝶遣返 → 期望：面板、时间线档案、Canon revision 全部照常。
- [ ] 跑一次**传记**或**墟境**生成（会走四模块检索）→ 期望：生成正常完成，正文/史稿没有被"少了蝴蝶史料"打崩。
- [ ] **控制台看两行**（internal.88 v3 新增，一眼判定供料是否成立）：
  - `butterfly sources: records=N committed=M effective=K revision=R` —— `effective` ≥ 1 即说明当前分支仍有有效蝴蝶史料进入检索（若是 0 而档案明显有效，记录并反馈）；
  - `canon view: task=… applied=… …` —— `applied` 有值即说明 Canon 投递正常。
- [ ] 正文层：推进 1~2 楼，确认改写后历史仍能自然带出（这是步 B 的准入证据——镜像未挂载时 `CANON_MEMORY` 已独立承担可见性）。

### 7. 不再自动挂载

- [ ] 清理后再遣返一次 → 检查 ST 全局世界书列表：**不应**重新出现 `伊雍-蝴蝶效应锚定-*`。
- [ ] 反例判据：若 reappear → 说明还有重挂路径未删净，记录并反馈。

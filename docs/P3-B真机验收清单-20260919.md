# P3-B 真机验收清单（internal.95 候选）

> 状态：`DRIVER ACCEPTED（2026-09-20）`
> 范围：只验 P3-B“确定性局部重基线”
> 不在本轮：P3-C 模型协调、P4、提示词、检索或普通正文改造

## 1. 要证明什么

只证明三件事：

1. 没有明确依赖的两次穿越互不连坐。
2. 某个结果的唯一明确支撑被推翻时，只让依赖它的 operation 退出 active；同次干涉里的直接行动和独立兄弟结果仍然保留。
3. 删除造成冲突的遣返楼后，旧支撑、P2 局部消费和 Canon Memory 能自动恢复，不需要手工改数据库或清缓存。

全程必须保持 `modelCalls=0`。工作台刷新与导出不得新建聊天楼、revision 或生成请求。

## 2. 安装门

P3-B 候选版本为 `0.10.0-internal.95`：1,073,536 bytes，SHA-256 `BCBCB0235600D4B24F21AC1A926DBD1896C5659A170E543641BC289BA935166C`。P3-A 已验收的 internal.94 原包已归档到 `release/archive/0.10.0-internal.94-v1/`，不得删除该回退点。

安装后只启用一个“伊雍历史工作台”脚本，并先导出当前全部资料作为回退备份。

## 3. 最短三轮流程

优先沿用 P3-A 已经稳定命中的玲山监禁例子，避免重新发明测试素材。

### 第一轮：建立旧状态

在 480 年的梵尼亚墟境中明确完成：

```text
海因里希俘获十九岁的玲山·哈姆斯沃思，将她关入梵尼亚外环黑曜监牢，没收相机与稿件，并确认她仍在服刑。
```

遣返并归档。刷新“设置 → 数据管理 → Canon 局部状态”，导出 R1。

### 第二轮：无关干涉

进入另一个与玲山监禁没有依赖关系的历史事件，明确完成一项独立行动，例如：

```text
海因里希修复艾瑟嘉德皇宫高塔的一扇旧窗，并把修缮记录交给宫廷营造署；此事不涉及玲山、梵尼亚监牢或她的相机与稿件。
```

遣返并归档，导出 R2。

通过标准：

- R1 与 R2 的相关 operation 均为 `active`；
- 没有仅因“后提交”而把 R1 判成 orphaned；
- “确定性局部重基线”显示 `modelCalls=0`；
- P3-A 预演与 P3-B 实际状态可以同时存在，但只有 P3-B 区显示当前真实生效状态。

### 第三轮：明确推翻旧状态

再次进入与玲山监禁有关的历史空隙，明确完成：

```text
海因里希破坏黑曜监牢的枷锁，亲自护送玲山·哈姆斯沃思离开梵尼亚；她已经解除监禁并恢复自由，这一结果明确取代此前“仍在服刑”的状态。
```

遣返并归档，导出 R3。先确认新 operation 是 `replace` 且 `originalFactIds` 指向 R1 的监禁状态；若只有平行 `assert`，说明本轮尚未形成可机械裁决的冲突，应保留导出交回诊断，不能把它当作 P3-B 失败。

在确有 `replace + originalFactIds` 时，通过标准：

- R1 被替换的旧状态 operation 为 `superseded`；
- R2 的独立修窗 operation 继续 `active`；
- 不相关的直接行动、同 delta 兄弟结果不被整批删除；
- delta 若同时包含 active 与非 active operation，汇总为 `partially-active`；
- P1/P2/Canon Memory 不再消费 R1 已 superseded 的旧状态，只消费 active 安全子集；
- 没有旧正文被重写或删除；
- `modelCalls=0`，没有 P3-C/reconcile 请求。

## 4. 回滚恢复

删除第三轮遣返对应的助手楼并让现有回滚链完成，再刷新并导出 R4。

通过标准：

- 第三轮 revision 为 reverted；
- R1 的监禁状态重新 active；
- R2 的独立修窗事实始终 active；
- P2 局部状态与 Canon Memory 自动恢复到回滚后的 active 子集；
- 重载页面后结果一致，无需清缓存或手工编辑。

## 5. 硬失败

- 无依赖的 R2 因 R1/R3 冲突而 orphaned；
- 一个 operation 冲突导致整条 delta、整篇传记或全部后继一起失效；
- direct 玩家行动被下游结果反向判废；
- 回滚第三轮后，R1 仍无法恢复；
- 刷新/导出触发模型、生成楼层或新增 revision；
- `modelCalls` 不是 0；
- 任何结构问题截断遣返，而不是局部 uncertain/有界降级；
- 自动进入 P3-C 或出现 reconcile 模型请求。

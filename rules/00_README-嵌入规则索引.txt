# 伊雍规则索引：创作与运行契约分开

本目录是源码规则，不覆盖玩家角色卡世界书。编号便于定位，不表示全部文件都要发送给模型。当前装配以 src/prompts 与 src/runtime/ruleBundle.ts 为准。

## 创作 API 实际使用

- 墟境提纲：src/prompts/ruin.ts 的提纲提示、地点/内容方向、已选时期与文风、资格化证据及既有输出契约；不整体注入11。
- 墟境扩写：11_墟境历史期生成规则-API.txt，加冻结提纲、完整证据、时期/文风及既有扩写契约。
- 墟境任务：src/prompts/ruinTask.ts；12是开发交接说明，不是任务创作系统提示。
- 蝴蝶效应：01共享背景、15创作规则、九项详细参考、冻结锚点与完整证据，以及事实/输出契约。03检索和05重试校验属于脚本，不整体注入。
- 寻根溯源：实际计划提示使用01/13，扩写使用13。此次不改其规则、骰表或校验。
- 宗族谱系：09及该模块实际提示。此次不改其规则或模板。

旧 RuleSet 的 retrievalContract/validationContract 字段保留接口兼容，不表示这些文本仍被模型读取。来源的完整正文只投递一次；重复引用不等于截断。

## 现行流程

墟境探索下分生成、任务、蝴蝶效应。未入境只开放生成；入境锁住生成与再次进入，开放任务和蝴蝶控制台。后台浏览/编辑不建楼。

生成：地点与参考方向决定内容，时期是主基调，讲述/节奏/情绪是写法参考。多个候选可同一时期，shift 起止可以相同；四节点都可进入，不要求灾难或冲突。

任务：草案→审阅→确认只填输入框→玩家亲自发送才封缄→正文/MVU与唯一卡片。奖励数值由脚本计算，地域不明时按世界书明确的通用币/价值结算，不虚构币名。

返程：确认九项参考→按钮冻结完整行动与三锚→后台准备并校验→唯一玩家返程楼→授权落盘回读→正文触发→内核恢复现实→面板与 Canon 提交。口头遣返只由伊雍引导，不启动新事务。输入框文字保留，空时使用默认返程语。

同一有效返程玩家楼重抽复用完整结果；删除该玩家楼，下一次按钮重新准备。准备失败不是“已经遣返”，已返程后的归档失败也不让玩家回到墟境。

## 事实与创作的边界

当前有效 Canon 承接本聊天已改写部分，原世界书仍提供其余基线。身份、年龄、已知事件、成功契约、历史赎出连续性与同卡/聊天/轮次作用域保留。未知空白可以合理创作，不冒称明确史料。

软参考必须有实际创作作用，但不形成九项文学评分、额外拒收门或预定结局。不从人物现在的身份一刀切排除其真实过去；不为旧冲突槽、公文证物或玩家职业倒推故事。

完整原文不按字符硬切。检索仍负责选取有关资料，不是无差别发送整本世界书。本轮不重写检索、数据库、时空内核或输出 Schema。

蝴蝶原稿与 Canon 存于当前聊天本地数据；原文关键词召回由受控聊天注入通道提供。专用世界书镜像写入已退役，旧 mirror_pending 等状态名称仅兼容既有数据。核心世界书的伊雍人设、FP与对白仍独立维护。

## 保留的工程边界

- 模型不输出 HTML、面板、JSON Patch 或变量更新；显示与状态写回由对应脚本/正文/MVU负责。
- 不读取其他聊天资料，不用旧事件.伊雍或候选缓存恢复墟境状态。
- 来源代码、模板命令与世界书标题不是世界内的角色、器物和事件。
- 不用另一次模型调用为风格评分，不以偏好不符重试或切断全文。
- 密钥不进入资料、正文、日志或导出。
- 开发测试、真实模型验收、打包、安装、Git与发布是独立门。

已知未解决边界：“大陆”是控制台偏好，但现有结果枚举最高为跨国；本轮不改变协议。偏好是否扩大实际检索、复杂模糊称谓的召回质量仍属检索层验收，不能因规则重构就宣称已解决。
